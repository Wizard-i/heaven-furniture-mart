# 🪑 Heaven Furniture Mart — Championship Platform

**RACDOX Hackathon Submission** | Chattogram's Premier Bespoke Solid Teak Atelier  
*Engineered to set the gold standard in bespoke digital architecture.*

---

## 🌟 Executive Summary

**Heaven Furniture Mart** is an ultra-premium, multi-page bespoke furniture platform designed for Chattogram’s premier solid teak studio located on Agrabad Access Road. Tailored specifically for **30–40 year-old homeowners and corporate executives**, this solution balances *"simple er modde unique"* architectural minimalism with rich editorial luxury, authentic founder credibility, and interactive material exploration.

---

## 🏆 Key Championship Features

### 1. 🏛️ Complete Multi-Page Architecture
- **[index.html](file:///c:/RAcdox/heaven-furniture-mart/index.html)**: Master Flagship Homepage with 9 editorial sections.
- **[about.html](file:///c:/RAcdox/heaven-furniture-mart/about.html)**: 16-Year Heritage (2010–2026), 4 Guarantees, and Founder Profile.
- **[shop.html](file:///c:/RAcdox/heaven-furniture-mart/shop.html)**: Filterable Bespoke Catalog across 11 pieces (Living, Bedroom, Dining, Office, Accents).
- **[product.html](file:///c:/RAcdox/heaven-furniture-mart/product.html)**: Single-piece showcase with multi-angle gallery, specifications table, and direct WhatsApp ordering.

### 2. 👤 Authentic Founder Centerpiece (Abul Kalam Bhuiyan)
- Features the real photograph of founder **Abul Kalam Bhuiyan** at his office desk with a verified master artisan badge and personal craftsmanship pledge.

### 3. 🪵 Interactive Timber & Material Studio
- Interactive swatch switcher allowing clients to explore **Burma Teak**, **Chittagong Teak**, **Gamari Wood**, **Organic Cane Weave**, and **Brushed Antique Brass** with live grain details and durability specs.

### 4. 🪑 Draggable Curated Pieces Rail with Custom `Drag` Cursor
- Silky smooth horizontal drag container showcasing signature commissions, complete with a floating circular `Drag` cursor that tracks mouse movement naturally.

### 5. ⚙️ Interactive Bespoke Configurator & WhatsApp Generator
- A 3-step interactive selector (**Room Type → Timber Species → Finish**) that instantly formats a pre-filled WhatsApp commission inquiry to the founder.

### 6. ⚡ Zero-Build Native Performance
- Built with pure semantic **HTML5, Vanilla CSS3 custom variables, and ES6+ JavaScript**. 
- 0 build tools, 0 npm bloat, instant page loads, and 95+ Lighthouse performance.

## 🚀 How to Run & Verify

Open any `.html` file directly in any modern browser:
- `index.html`
- `about.html`
- `shop.html`
- `product.html`

Or run a local server:
```bash
python -m http.server 8000
# or
npx serve .
```
Then visit `http://localhost:8000`.
